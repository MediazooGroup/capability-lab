# Demo brief: the first useful manager conversation

Fictional organisation: Northstar Services. All people, quotes and policies in this demo are invented for teaching. Create a 10-minute practice activity for newly promoted managers preparing a first one-to-one conversation. The observable outcome is a manager asking an open question, listening and agreeing a next action. Use the three supplied approved source notes. Produce one scenario, two discussion questions, a facilitator note and a simple quality check. Identify which source supports each part. A learning lead reviews before use.
