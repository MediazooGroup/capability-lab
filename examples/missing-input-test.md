# Missing-input test

Input: “Make a manager activity.” No audience note, outcome or approved framework is supplied.

Expected behaviour under build-learning-asset: request the required missing information. Do not produce organisational policy or a supposedly approved activity.

Reference response:

> Who is the activity for, what should they be able to do afterwards, and which approved sources or framework should I use? Please also name the person who will review it. Once I have those inputs, I can draft the activity and show which source supports each design choice.

Pass condition: a request for the missing evidence, without an invented learning asset. Failing behaviour: a confident generic activity presented as source-grounded or approved.
