# Check session

Read the actual brief and current artifact inventory. Verify the 30-minute timing, six promised content topics, engagement/visibility/impact thread, interactive diagram and audience takeaway. Inspect every slide at full size and on a projector-size viewport. Check the ending shows the real build provenance.

Run the app's unit and browser suites in a clean test context. Exercise source selections, skill export, pilot calculations, storage recovery, reset confirmation, keyboard controls, phone layouts, accessibility, downloads and offline fallback. Inspect the generated markdown, archive contents and offline web presentation. A passing build alone is insufficient.

Check the deployed URL and download as an unauthenticated attendee. A private deployment does not satisfy audience access. Record the exact commands, counts, browsers, dates and limitations in the test report. Do not call untested browsers or venue Wi-Fi verified. Fix material failures and rerun affected checks.

Test a second brief and a missing-input case through the learning skill. Verify citations and avoid unsupported claims. The completion decision must cover the requested end state, not only the easy passing parts.
