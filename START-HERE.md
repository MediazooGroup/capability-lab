## Get this example live: three steps

1. On [GitHub](https://github.com/MediazooGroup/capability-lab), choose **Code → Download ZIP**. Unzip it. No GitHub account is needed to download.
2. Open **launch-ready/index.html** in Chrome, Edge, Firefox or Safari. This is the already-built interactive board. No installation or terminal commands are needed to try it.
3. To share your copy online, sign in to [Netlify Drop](https://app.netlify.com/drop). Drag the whole **launch-ready** folder onto the page. Open the live URL it gives you, test it on a phone, then share it. Hosting account terms and plan limits apply. [Netlify’s instructions](https://docs.netlify.com/deploy/create-deploys/#deploy-with-drag-and-drop).

That publishes the supplied example. The next section helps you change what it teaches.

## Make a board for your own topic

1. Open this unzipped folder in an AI coding tool with file and code access, such as Codex or Claude Code. Ask it to read **learning-brain/INDEX.md** and **skills/build-learning-board/SKILL.md**. A normal chat can help you write the brain; building and previewing the web app needs code execution.
2. Copy and paste this prompt. Replace the two brackets:

> Help me adapt this learning board to teach **[my topic]** to **[my audience]**. Read learning-brain/INDEX.md and skills/build-learning-board/SKILL.md. First ask what learners should be able to do and which sources I want you to use. Help me create the brain, then build the interactive board. Show it to me, refine it from my feedback, check it, and rebuild the launch-ready folder. Follow REBUILD.md for the commands. Keep the original example until I have reviewed my version.

3. Give it your approved source knowledge: a process guide, framework, product notes or examples. Start with one useful learning outcome.
4. Try the result as a learner. Ask for a specific improvement: “Give me a realistic decision, explain every answer, and let me rehearse it.” Review the accuracy and suitability.
5. When the revised **launch-ready** folder is ready, upload that folder to your hosting project and check the new live version.

## Edit just the diagram

Open [Excalidraw](https://excalidraw.com), use its menu to open **output/better-one-to-ones.excalidraw**, and change the canvas. You can also choose **Edit a copy** inside the learning board and **Save board** to keep your changes.

Changing the diagram alone does not rewrite the learning panel or publish a new website. To change the whole learning experience, update the brain and rebuild it with the skill.

## Keep the loop going

**Create the brain → use the skill → build → refine → launch.**

The Northstar organisation, Sam scenario and Ask/Listen/Agree framework are illustrative. Review your version with a subject owner before treating it as organisational training. Replace Finer Vision and Mediazoo identity with your own when you adapt the session. Keep private source material inside your approved environment.
