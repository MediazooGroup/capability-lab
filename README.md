# A brain. A skill. A learning board.

Everything in this workshop was built using the same pattern: **create a brain for something worth teaching, use a skill to build it, refine it, then launch it.**

This repository contains the actual learning brain, the reusable skill and the finished interactive Excalidraw dashboard — plus the source and skills behind John Gordon’s Peritus presentation.

**[Try the board](https://peritus-capability-lab.john959475.chatgpt.site/board) · [Read the brain](https://peritus-capability-lab.john959475.chatgpt.site/brain) · [Open the presentation](https://peritus-capability-lab.john959475.chatgpt.site/present)**

## Download and get live

1. **Code → Download ZIP**, then unzip.
2. Open **launch-ready/index.html** to try the finished example.
3. Sign in to [Netlify Drop](https://app.netlify.com/drop), upload the **launch-ready** folder, and share the URL it gives you.

**[START-HERE.md](START-HERE.md)** has the simple instructions and a prompt to make a new board for your own topic. No GitHub account is needed to download.
