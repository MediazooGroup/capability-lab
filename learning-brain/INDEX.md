# Better first one-to-ones: the learning brain

This is the actual source for the interactive Excalidraw learning board. It teaches one observable behaviour: open a first one-to-one, listen before advising, and agree a next step together.

A fictional worked example for new managers at Northstar Services. This is an illustrative learning design, not an organisational policy or a validated management model.

## Read in this order
1. [The brief](00-brief.md): what the asset must achieve.
2. [The audience](01-audience.md): who it must work for.
3. [The knowledge](02-framework.md): Ask, Listen, Agree.
4. [The practice](03-scenarios.md): decisions, feedback and rehearsal.
5. [The quality bar](04-quality.md): what must pass before launch.
6. [The refinement](05-refinements.md): how the first draft changed.

`board.json` is the structured lesson content used by the build script. It contains the same teaching content, source links and review decisions. Edit this file alongside the notes when adapting the example; run the sync and board build scripts before rebuilding the app.

Use `skills/build-learning-board/SKILL.md` to turn your own small brain into a similar asset. Keep the method; replace the subject, audience and examples.
